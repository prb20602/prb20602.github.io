Procedure to Install Python Environment for AI & ML

Procedure (Linux Steps)

Step 1: Check Existing Python Installation

python3 --version

If Python is not installed:

sudo apt update
sudo apt install python3

Step 2: Install pip (Python Package Manager)

pip3 --version

If not installed:

sudo apt install python3-pip

Step 3: Upgrade pip

pip3 install --upgrade pip

Step 4: (Optional) Create Virtual Environment

sudo apt install python3-venv
python3 -m venv ai_ml_env
source ai_ml_env/bin/activate

Step 5: Install Required AI & ML Libraries

pip install numpy
pip install pandas
pip install matplotlib
pip install seaborn
pip install scikit-learn
pip install tensorflow
pip install keras

Step 6: Verify Installation

python3
import numpy
import pandas
import matplotlib
import sklearn
import tensorflow
import keras
print("All libraries imported successfully")

Sample Output

All libraries imported successfully

Procedure (Windows Steps)

Step 1: Download and Install Python

  • Open a web browser and visit https://www.python.org
  • Download Python 3.x (64-bit) for Windows
  • Run the installer
  • ✔ Check Add Python to PATH
  • Click Install Now

Step 2: Verify Python Installation

python --version
Expected Output:
Python 3.x.x

Step 3: Verify pip Installation

pip --version
python -m ensurepip --upgrade

Step 4: Upgrade pip

python -m pip install --upgrade pip

Step 5: (Optional) Create Virtual Environment

python -m venv ai_ml_env
ai_ml_env\Scripts\activate

Step 6: Install Required AI & ML Libraries

pip install numpy
pip install pandas
pip install matplotlib
pip install seaborn
pip install scikit-learn
pip install tensorflow
pip install keras

Step 7: Verify Installation

python
import numpy
import pandas
import matplotlib
import sklearn
import tensorflow
import keras
print("Libraries imported successfully")

Step 8: Install Jupyter Notebook (Optional)

pip install notebook
jupyter notebook

Sample Output

Libraries imported successfully

Result

Thus, the Python environment required for Artificial Intelligence and Machine Learning was successfully installed on Windows OS, and all essential Python libraries were imported without errors.

Conclusion

Windows provides a convenient platform for AI & ML development. By installing Python and the required libraries, a complete development environment for machine learning applications is achieved.
